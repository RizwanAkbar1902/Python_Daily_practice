\# 🏦 Day 19 - Bank Account Simulator



\## 📖 Description



The \*\*Bank Account Simulator\*\* is a console-based Python application

designed to simulate basic banking operations using Object-Oriented

Programming (OOP).



The program creates bank account objects and demonstrates common

operations such as depositing money, withdrawing money, checking

balances, and displaying account information.



\---



\## ✨ Features



\- 🏦 Create bank account objects

\- 💰 Deposit money

\- 💸 Withdraw money

\- 🛡️ Prevent withdrawals exceeding the available balance

\- ⚠️ Validate invalid transaction amounts

\- 📊 Display account information

\- 👥 Manage multiple accounts using a dictionary
