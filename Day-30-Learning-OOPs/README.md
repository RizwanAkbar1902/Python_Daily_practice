# Employee Management System (Core OOP)

A lightweight Python implementation demonstrating fundamental Object-Oriented Programming (OOP) concepts: creating blueprints with classes, initializing unique instances with constructors, and encapsulating data.

## Features

- **Dynamic Attributes:** Automatically generates business emails using first and last name properties.
- **Instance Methods:** Implements reusable methods for formatted employee identification.
- **Encapsulation:** Keeps data organized cleanly within custom class objects.

## Getting Started

### Prerequisites

- Python 3.8+ installed on your system.

### Running the Code
