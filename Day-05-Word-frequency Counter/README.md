\# Word Frequency Counter 📊



A simple, interactive command-line Python script that analyzes an input sentence, cleans the text, and calculates the exact frequency of each word.



\---



\## 📖 Features



\- \*\*Text Normalization\*\*: Converts all text to lowercase to ensure case-insensitive matching (e.g., `Python` and `python` are counted together).

\- \*\*Punctuation Removal\*\*: Strips out commas, periods, and special symbols using Python's `string.punctuation`.

\- \*\*Frequency Dictionary\*\*: Maps each unique word to its appearance count.

\- \*\*Summary Metrics\*\*: Displays total word count, total unique words, and highlights the most frequent word.



\---



\## 🛠️ Concepts Practiced



\- \*\*Dictionaries\*\*: Creating key-value pairs and updating counts (`dict\[key] += 1`).

\- \*\*Strings\*\*: `.lower()`, `.translate()`, and `.split()`.

\- \*\*Loops \& Conditions\*\*: Iterating through dictionary keys and finding maximum values.

\- \*\*Functions\*\*: Writing modular, single-responsibility functions.
