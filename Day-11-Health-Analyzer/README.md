Day 11: BMI Health Analyzer
A command-line Python script that calculates Body Mass Index (BMI) and provides health classification feedback.

Overview
The program takes a user's weight in kilograms and height in meters, calculates the BMI using the standard formula, and outputs the result with a relevant health category.

Formula Used
BMI = Weight (kg) / (Height (m))^2

BMI Classification
Underweight: BMI less than 18.5

Normal Weight: BMI between 18.5 and 24.9

Overweight: BMI between 25.0 and 29.9

Obese: BMI 30.0 or higher

Key Programming Concepts
Converting user inputs with float()

Exponentiation and division operators

Output formatting with f-strings ({bmi:.2f})

Conditional branching using if, elif, and else
