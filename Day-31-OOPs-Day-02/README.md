# Simple Mobile Class (OOP Basics)

A beginner-friendly Python program demonstrating the fundamentals of Object-Oriented Programming (OOP) using a real-world mobile phone example.

## What This Code Demonstrates

- **Class & Constructor:** Defining a blueprint using `class` and assigning initial values using `__init__`.
- **Instance Variables:** Storing phone details like `brand`, `model`, and `battery`.
- **Methods:** Modifying the phone's state using simple functions (`make_call` and `charge`).

## How to Run

```bash
python mobile.py
