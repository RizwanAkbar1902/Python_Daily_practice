\# Rock Paper Scissors Game (Python)



A simple, interactive command-line Rock, Paper, Scissors game built using basic Python concepts.



\### Concepts Practiced:

\- `random.choice()` for randomized computer selection

\- Input validation and string cleaning (`.strip().lower()`)

\- Game loops with `while True` and `break` / `continue`

\- Score tracking using simple integer counters

\- Boolean logic with `and` / `or` conditions



\### How to Run:

```bash

python game.py
