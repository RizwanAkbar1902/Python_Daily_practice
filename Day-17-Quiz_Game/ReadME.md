\# 🎮 Day 17 - Quiz Game



\## 📖 Description



A console-based Python quiz game containing 10 multiple-choice questions.



The program accepts answers from A to D, validates user input, checks each

answer, calculates the final score, and provides performance feedback.



\## ✨ Features



\- 10 multiple-choice questions

\- A/B/C/D answer validation

\- Invalid input retry system

\- Automatic score calculation

\- Correct answer feedback

\- Final percentage score

\- Performance remarks



\## 🛠️ Concepts Practiced



\- Lists

\- Dictionaries

\- Functions

\- For Loops

\- While Loops

\- Conditional Statements

\- User Input Validation

\- String Methods

\- Score Calculation
