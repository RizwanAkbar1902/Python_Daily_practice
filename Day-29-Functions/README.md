\# 💰 Day 22 - Bill Generator



\## 📖 Description



The Bill Generator is a console-based Python application that calculates

discounts, taxes, and final bill amounts using reusable functions.



The project was created to strengthen my understanding of Python functions

and improve my ability to organize logic into separate, reusable components.



\## ✨ Features



\- 🧾 Generate a formatted bill

\- 💸 Calculate discounts

\- 💰 Calculate tax

\- 📊 Calculate the final total

\- ⚠️ Validate numeric input

\- 🛡️ Prevent invalid prices and discount percentages

\- 🔄 Use reusable functions

\- 🎯 Use default function parameters



\## 🛠️ Concepts Practiced



\- Functions

\- Parameters and Arguments

\- Return Values

\- Default Parameters

\- Function Composition

\- Exception Handling

\- Input Validation

\- String Formatting

\- Floating-Point Formatting

\- `main()` Function
