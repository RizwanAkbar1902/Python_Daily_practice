\# Student Grade Book Manager 📚



A beginner-friendly, interactive command-line Python application to manage student records and track grades.



\---



\## 🚀 Features



\- \*\*Search Student\*\*: Look up any student by name to see their grade and status (`Passed` vs `Need Improvement`).

\- \*\*Add / Update Records\*\*: Add new students or update existing student scores dynamically.

\- \*\*Display Inventory\*\*: View a complete list of all registered students alongside total class strength.

\- \*\*Safe Input Handling\*\*: Validates menu selections and score entries to prevent invalid inputs.



\---



\## 🛠️ Concepts Practiced



\- \*\*Dictionaries\*\*: Key-value mapping for student names and grades (`student\[name] = grade`).

\- \*\*Loops \& Control Flow\*\*: Interactive `while` loop with `if / elif / else` branching.

\- \*\*String Formatting \& Methods\*\*: `.strip()`, `.capitalize()`, and `.isdigit()`.
