\# 📱 Day 16 - Phonebook Manager



\## 📖 Description



The \*\*Phonebook Manager\*\* is a console-based Python application that allows users to manage contacts. Users can add new contacts, search for existing contacts, view all saved contacts, and delete contacts through a simple menu-driven interface.



\---



\## ✨ Features



\- ➕ Add a new contact

\- 🔍 Search for a contact

\- 📋 View all contacts

\- 🗑️ Delete a contact

\- 🚪 Exit the application



\---



\## 🛠️ Concepts Used



\- Python Dictionaries

\- While Loops

\- Conditional Statements (`if-elif-else`)

\- Dictionary Methods

\- User Input
