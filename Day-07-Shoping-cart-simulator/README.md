\# Shopping Cart Simulator 🛒



A beginner-friendly command-line shopping cart program written in Python that allows users to manage inventory items and quantities in real time.



\---



\## 🚀 Features



\- \*\*Add Items\*\*: Adds new items or increments quantity if the item is already present in the cart.

\- \*\*Partial/Complete Removal\*\*: Remove specific quantities of an item or discard it entirely once the count reaches zero.

\- \*\*View Cart Summary\*\*: Lists each item with aligned formatting and calculates total unique items and total unit count.

\- \*\*Input Validation\*\*: Prevents script crashes against non-numeric inputs using `.isdigit()`.



\---



\## 🛠️ Concepts Covered



\- Python Dictionaries (`dict\[key] += value`, `.pop()`, `.values()`)

\- Dynamic calculations using built-in `sum()` and `len()`

\- `while` loop control with string parsing methods (`.strip()`, `.capitalize()`)
