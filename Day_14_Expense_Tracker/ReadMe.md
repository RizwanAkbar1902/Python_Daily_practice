\# 💰 Day 14 - Expense Tracker



\## 📖 Description

The \*\*Expense Tracker\*\* is a simple console-based Python application that helps users record and manage their daily expenses. Users can add expenses, view all recorded expenses, and calculate the total amount spent.



\---



\## ✨ Features

\- ➕ Add a new expense

\- 📋 View all recorded expenses

\- 💰 Calculate the total expense

\- 🚪 Exit the application safely



\---



\## 🛠️ Concepts Used

\- Python Dictionaries

\- While Loops

\- Conditional Statements (`if-elif-else`)

\- User Input

\- Dictionary Methods

\- `sum()` Function
