Day 12 Username Validator
A clean CLI Python script that evaluates whether a user-provided username meets standard format and security criteria.

Validation Rules
A valid username must satisfy all of the following

Length must be between 5 and 15 characters.

Must start with an alphabet letter (A-Z, a-z).

Must not contain any spaces.

Can only consist of alphanumeric characters and underscores (_).

Key Programming Concepts
String manipulation and trimming using .strip()

Character checking via .isalpha() and .isalnum()

String substitution using .replace()

Conditional evaluations using if, elif, and else

How to Run
Execute the script via terminal
