# 📊 Day 13 - Text Statistics Analyzer

## 📖 Description

The **Text Statistics Analyzer** is a simple Python program that analyzes
a user-provided sentence and generates useful text statistics.

It examines the entered text and calculates the number of characters,
words, vowels, consonants, digits, and spaces.

## ✨ Features

- 🔤 Counts total characters
- 📝 Counts total words
- 🔡 Counts vowels
- 🔠 Counts consonants
- 🔢 Counts digits
- ␣ Counts spaces
- 📊 Displays results in a clear format

## 🛠️ Concepts Used

- Strings
- `input()`
- `len()`
- `split()`
- `for` loops
- `if / elif` statements
- String methods
- `.lower()`
- `.isalpha()`
- `.isdigit()`
- `.isspace()`

## ⚙️ How It Works

The program follows these basic steps:

```text
User enters text
       ↓
Program analyzes each character
       ↓
Counts characters, words, vowels,
consonants, digits, and spaces
       ↓
Displays the final statistics
```

## ▶️ How to Run

Run the Python file using:

```bash
python Day_13_Text_Statistics_Analyzer.py
```

Then enter any sentence when prompted.

### Example

```text
Enter a sentence: Python 123 is amazing!

Total Characters : 21
Total Words      : 4
Total Vowels     : 6
Total Consonants : 9
Total Digits     : 3
Total Spaces     : 3
```
