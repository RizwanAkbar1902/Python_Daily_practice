\# ✅ Day 18 - To-Do Manager



\## 📖 Description



The To-Do Manager is a console-based Python application that allows users

to create and manage tasks through a simple menu-driven interface.



Users can add tasks, view their current tasks, mark tasks as completed,

and delete tasks.



\---



\## ✨ Features



\- ➕ Add new tasks

\- 📋 View all tasks

\- ✅ Mark tasks as completed

\- 🗑️ Delete tasks

\- ⚠️ Input validation

\- 🔄 Menu-driven interface

\- 🚫 Prevents empty task names

\- ℹ️ Detects already completed tasks



\---
