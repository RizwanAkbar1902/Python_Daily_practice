# 🔢 Even, Odd & Multiple of 5 Checker

## 📖 Description

This is a simple Python program that checks whether a user-entered
number is **Even or Odd** and also determines whether the number is
a **multiple of 5**.

The program uses conditional statements and the modulo (`%`) operator
to perform the checks.

## ✨ Features

- Checks whether a number is Even or Odd
- Checks whether the number is a multiple of 5
- Provides clear output for each condition
- Uses nested `if-else` statements

## 🛠️ Concepts Used

- Variables
- User Input
- Integer Conversion
- `if-else` Statements
- Nested Conditional Statements
- Modulo (`%`) Operator
- Comparison and Logical Conditions

## ▶️ How It Works

The program:

1. Takes a number from the user.
2. Checks whether the number is divisible by 2.
3. Determines whether it is Even or Odd.
4. Checks whether the number is divisible by 5.
5. Displays the result.
