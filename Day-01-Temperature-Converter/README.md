# 🌡️ Temperature Conversion Program

## 📖 Description

A simple Python program that converts temperatures between
Celsius and Fahrenheit using a menu-driven interface.

## ✨ Features

- 🌡️ Celsius to Fahrenheit conversion
- 🔥 Fahrenheit to Celsius conversion
- 🔄 Menu-based interaction
- 🚪 Exit option

## 🛠️ Concepts Used

- Variables
- User Input
- Type Conversion
- `while` Loop
- `if-elif-else`
- Arithmetic Operators
- Temperature Conversion Formulas
