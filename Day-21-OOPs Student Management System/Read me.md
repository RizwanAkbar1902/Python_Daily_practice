\# 🎓 Day 21 - Student Management System



\## 📖 Description



The \*\*Student Management System\*\* is a Python project designed to

practice Object-Oriented Programming (OOP) through a simple

school management scenario.



The system allows a school manager to register students, enroll

students in courses, and display student information.



\---



\## ✨ Features



\- 🎓 Create student objects

\- 🏫 Manage registered students

\- 📚 Enroll students in courses

\- 🚫 Prevent duplicate course enrollment

\- 🆔 Prevent duplicate student IDs

\- 📋 Display student information

\- 🛡️ Basic input validation



\---



\## 🛠️ Concepts Practiced



\- Classes and Objects

\- `\_\_init\_\_()` Constructors

\- Encapsulation

\- Private Attributes

\- Methods

\- Type Hints

\- Lists

\- Dictionaries

\- Conditional Statements

\- Object Composition
