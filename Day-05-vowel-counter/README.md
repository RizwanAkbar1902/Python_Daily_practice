# 🔤 Vowel Counter

## 📖 Description

A simple Python program that counts the total number of vowels
present in a sentence entered by the user.

The program checks each character and counts the vowels
(A, E, I, O, U) regardless of uppercase or lowercase.

## ✨ Features

- 📝 Accepts a sentence from the user
- 🔤 Detects vowels in the sentence
- 🔢 Counts the total number of vowels
- 🔠 Supports both uppercase and lowercase vowels

## 🛠️ Concepts Used

- Strings
- Variables
- User Input
- `for` Loop
- `if` Statement
- Membership Operator (`in`)
- Counter Variable

## ⚙️ How It Works

```text
User enters a sentence
        ↓
Program checks each character
        ↓
Checks whether it is a vowel
        ↓
Increases the counter
        ↓
Displays total vowels
