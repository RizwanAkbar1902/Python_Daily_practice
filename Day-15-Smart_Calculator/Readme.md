\# 🧮 Day 15 - Smart Calculator



\## 📖 Description



The \*\*Smart Calculator\*\* is a console-based Python application that performs common mathematical operations through a simple menu-driven interface. It demonstrates modular programming by organizing each operation into separate functions while ensuring user-friendly input validation.



\---



\## ✨ Features



\- ➕ Addition

\- ➖ Subtraction

\- ✖️ Multiplication

\- ➗ Division

\- 🔢 Power Calculation

\- 🧮 Modulus (Remainder)

\- 🔄 Multiple calculations without restarting the program

\- ⚠️ Error handling for invalid input

\- 🚫 Protection against division and modulus by zero



\---



\## 🛠️ Concepts Used



\- Functions

\- While Loops

\- Conditional Statements (`if-elif-else`)

\- Exception Handling (`try-except`)

\- User Input Validation

\- Arithmetic Operators
