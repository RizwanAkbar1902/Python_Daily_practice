\# Python OOP Basics 🚀



A beginner-friendly, clean Python project demonstrating the core principles of \*\*Object-Oriented Programming (OOP)\*\*. 



This project shows how to build real-world models using small, understandable code components.



\---



\## 📚 Concepts Covered



1\. \*\*Classes \& Objects\*\*: Creating blueprints (`Person`, `Student`) and instantiating real objects.

2\. \*\*Constructors (`\_\_init\_\_`) \& `self`\*\*: Initializing object attributes upon creation.

3\. \*\*Inheritance\*\*: `Student` class inherits common properties from the parent `Person` class using `super()`.

4\. \*\*Encapsulation\*\*: Protecting sensitive data by making the marks attribute private (`\_\_marks`).



\---



\## 🛠️ Project Structure



\- `main.py`: Contains the class definitions and execution script.

\- `README.md`: Project documentation.
